# Proyecto Movilidad Paiporta / Valencia

This repository contains two layers of work:

- **`notebooks/`** — the original university-internship data-science work
  (Sept–Oct 2025, in Spanish): extracting Valencia's road network, cleaning and
  imputing it, spatially joining loop-sensor data, and modelling traffic
  congestion.
- **`EDM/`** — the **EDM course project**: an interactive, deployed Streamlit
  application built on top of that engine.
  **→ See [`EDM/README.md`](EDM/README.md) for the app, methodology, and how to run/deploy it.**

```bash
.venv/bin/streamlit run EDM/app/app.py
```
